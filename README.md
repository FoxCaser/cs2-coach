# CS2 Coach

Стартова версія персонального CS2 coach/analyzer.

## Уже є
- адаптивний інтерфейс для ПК і телефона;
- Dashboard;
- швидкий локальний аналіз K/D, HS%, ADR;
- план тренувань;
- секції Прогрес і Профіль;
- Node.js + Express API;
- структура, яку можна розширювати без переписування всього сайту;
- готовність до Render.

## Локальний запуск
```bash
npm install
npm start
```

Після запуску відкрий:
http://localhost:3000

## Наступні модулі
1. Steam authentication.
2. Реальна статистика матчів.
3. PostgreSQL.
4. AI analysis.
5. Match history / demo parser.
6. Прогрес і графіки.
7. Налаштування профілю.
